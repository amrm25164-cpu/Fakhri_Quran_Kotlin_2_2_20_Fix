# فخري قرآن — Fakhri Quran

مشروع Flutter عربي لقارئ القرآن الكريم وأدوات القراءة والتلاوة. يحتوي على خط عثماني حفص الذي أرسله المستخدم.

## الوظائف المنفّذة في المشروع

- قائمة السور الـ114، وقراءة النص بالرسم العثماني من AlQuran Cloud.
- تخزين دائم لنص كل سورة بعد تحميلها، مع خيار تنزيل نص القرآن كاملًا للقراءة دون إنترنت.
- بحث داخل السورة وبحث عام في القرآن عبر واجهة AlQuran Cloud.
- عرض التفسير الميسر أو ترجمات متاحة (الإنجليزية والفرنسية والأردية)؛ يمكن تنزيل بعض الإصدارات لجميع السور للاستخدام دون إنترنت.
- تشغيل الآيات أو السورة كاملة، واختيار قارئ من قائمة مصادر EveryAyah.
- تنزيل سورة أو التلاوات المتاحة للقارئ المختار إلى مساحة التطبيق الخاصة، والتشغيل من الملفات المحلية بعد تنزيلها.
- حفظ آخر موضع قراءة، وعلامات الآيات، والمفضلة، وحجم الخط، والوضع الداكن، وعدادات الأذكار.
- استيراد خطوط TTF/OTF من الجهاز واستخدام خط عثماني حفص المرفق.
- مواقيت صلاة حسب المدينة عبر AlAdhan، مع خيار جدولة تذكيرات يومية. التوقيت وطريقة الحساب قد يختلفان عن جهة بلدك؛ راجع المصدر المحلي.
- حساب زاوية القبلة من إحداثيات يدخلها المستخدم، مع سهم بوصلة عند توفر مستشعر الهاتف.
- أذكار أساسية بعدّادات مستقلة محفوظة محليًا.
- استوديو تصميم عمودي للآيات، وتصدير صورة PNG أو فيديو MP4 ثابت التصميم مع تلاوة الآية المختارة.

## مصادر البيانات

- **النص وقائمة السور والترجمات:** [AlQuran Cloud API](https://alquran.cloud/api)
- **التلاوات الصوتية:** [EveryAyah](https://everyayah.com/)
- **مواقيت الصلاة:** [AlAdhan Prayer Times API](https://aladhan.com/prayer-times-api)
- **توليد MP4:** حزمة [ffmpeg_kit_flutter_new](https://pub.dev/packages/ffmpeg_kit_flutter_new). الحزمة الكاملة تتضمن مكونات GPL؛ راجع الترخيص قبل التوزيع أو النشر التجاري.

## نقاط مهمة

- يلزم الإنترنت للتحميل الأولي للنصوص والترجمات والتلاوات غير المحمّلة.
- تنزيل الصوت الكامل قد يحتاج مساحة تخزين كبيرة جدًا؛ يفضّل تنزيل السور التي تحتاجها فقط. لا تتوفر كل ملفات الصوت لكل قارئ بالضرورة.
- التذكيرات اليومية تستخدم توقيت المدينة التي حمّلت مواقيتها، وتحتاج إذن الإشعارات. قد تؤخر بعض أجهزة Android الإشعارات بسبب إعدادات البطارية.
- زاوية القبلة صحيحة بحسب الإحداثيات التي تدخلها، أما سهم البوصلة فيتوقف على توفر مستشعر واتجاهه ومعايرته.
- يجب مراجعة حقوق استخدام التسجيلات والخط قبل نشر التطبيق.

## بناء APK على GitHub

1. ارفع محتويات المجلد `fakhri_quran` إلى مستودع GitHub.
2. افتح تبويب **Actions**.
3. شغّل **Build Fakhri Quran APK** من زر **Run workflow**، أو ادفع commit إلى فرع `main` أو `master`.
4. بعد نجاح العملية، افتح نتيجة التشغيل ونزّل artifact باسم `fakhri-quran-release-apk`.

الـ workflow ينشئ ملفات Android المناسبة لإصدار Flutter المستقر الموجود على runner، ثم ينفّذ `flutter pub get` والتحليل والاختبارات وبناء APK. لم أتمكن من تنفيذ Flutter محليًا في بيئة التأليف الحالية، لذلك يجب اعتبار نجاح الـ workflow واختبار التطبيق على جهاز Android شرطًا قبل النشر.


## إصلاح خطأ Gradle في Klencod IDE
إذا ظهر أن Gradle 8.7 أقدم من الحد المطلوب 8.14.0، تم تحديث `android/gradle/wrapper/gradle-wrapper.properties` إلى Gradle 8.14.3. ارفع هذه النسخة إلى GitHub وشغّل workflow مرة أخرى. تحذيرات Node.js أو setup-java ليست سبب الخطأ المذكور.
